## Что нужно сделать в Supabase:

### 1️⃣ SQL Миграция (самое важное!)

1. Откройте https://app.supabase.com/ → ваш проект
2. Откройте **SQL Editor**
3. Нажмите "+ New Query"
4. Скопируйте весь текст из файла `supabase_migration.sql`
5. Нажмите ▶ Run

Должны создаться таблицы:
```
✓ pattern_reports (для репортов пользователей)
✓ hidden_patterns (для скрытых паттернов)
```

### 2️⃣ Service Role Key

1. Settings → API
2. Скопируйте **service_role** ключ
3. Вставьте в `.env`:
```
SUPABASE_SERVICE_ROLE_KEY=sk_service_..........
```

### 3️⃣ На Vercel добавьте:

```
ADMIN_USER_ID = user_1767857068696
SUPABASE_SERVICE_ROLE_KEY = sk_service_..........
```

(остальные ключи уже есть)

## Как это работает:

1. **Юзер видит паттерн** на карте
2. **Нажимает Report** (жёлтая кнопка)
3. **Открывается модал** с полем для комментария
4. **Репорт отправляется** в `pattern_reports` таблицу
5. **Админ (ты) видит репорты** в `/admin` панели
6. **Админ нажимает Accept** → паттерн добавляется в `hidden_patterns`
7. **Следующий раз** когда кто-то откроет страну → паттерн не видно (фильтрован)

## Структура БД:

### pattern_reports
```
id (uuid) — уникальный ID репорта
country_id (text) — ID страны (e.g. "12")
pattern (text) — паттерн (e.g. "-ium")
user_id (uuid) — ID пользователя который репортил
reason (text) — причина (опционально)
comment (text) — комментарий (опционально)
status (text) — "pending" | "accepted" | "rejected"
created_at (timestamp) — когда репортили
updated_at (timestamp) — когда обновили статус
```

### hidden_patterns
```
id (uuid) — уникальный ID
country_id (text) — ID страны
pattern (text) — паттерн
created_at (timestamp) — когда скрыли
```

## Тестирование:

1. Авторизуйтесь на сайте (Sign in)
2. Найдите любой паттерн
3. Нажмите жёлтую кнопку "Report"
4. Заполните комментарий (опционально)
5. Нажмите "Отправить"
6. Откройте Admin панель (ссылка должна быть в хэдере)
7. Увидите репорт с картой
8. Нажмите "Accept" чтобы скрыть паттерн
9. Закройте страну и откройте снова → паттерна больше нет
